6. I/O and OS Depth (32 features) — symlinks, glob, walk, buffered I/O, signals
7. Testing Depth (18 features) — subtests, fixtures, table-driven, skip, assert variants
8. Spec and Documentation (20 sections) — comprehensive language specification
